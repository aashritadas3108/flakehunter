# FlakeHunter



Hey! I'm building FlakeHunter, a tool to find and understand flaky tests in Python's pytest.

Sometimes a test passes, sometimes it fails, even when the code hasn't changed. I'm working on a way to detect these tests, figure out what might be causing the issue, and make debugging a little easier.

**What I'm working on:**
- Finding tests that pass and fail inconsistently.
- Trying smarter ways to rerun tests without wasting too much time.
- Looking for possible causes like timing issues, test order, and shared state.

This project is a work in progress, and I'm building it step by step while learning more about Python testing and software engineering.
